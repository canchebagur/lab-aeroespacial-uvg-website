abstract: >
    <div style="text-align: justify;">
    Este artículo presenta las consideraciones de diseño y desarrollo para el subsistema de Comando y Manejo de Datos (C&DH) del QUETZAL-1, el primer satélite de Guatemala. El sistema C&DH sirve como la unidad de procesamiento central del satélite, gestionando todas las operaciones a bordo, el almacenamiento de datos y la comunicación entre subsistemas. Se discuten las decisiones clave de diseño, la selección de hardware, la arquitectura del software y las lecciones aprendidas durante el proceso de desarrollo. El trabajo proporciona información sobre los desafíos enfrentados al desarrollar un sistema C&DH de CubeSat con recursos limitados y las soluciones implementadas para garantizar una operación confiable en el entorno espacial.
    </div>
